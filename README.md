Анализ стоп-кодонов в геноме E. coli

Что это
Учебный проект по биоинформатике. Анализ частоты встречаемости стоп-кодонов (TAA, TAG, TGA) в геноме бактерии Escherichia coli.

Что делает
1. Читает геном E. coli из локального файла ecoli.fasta.
2. Ищет три вида стоп-кодонов: TAA, TAG, TGA.
3. Считает, сколько раз каждый из них встречается в геноме.
4. Строит столбчатую диаграмму для визуализации результатов.

Результаты
• Количество TAA: 68858
• Количество TAG: 27254
• Количество TGA: 83532

Стек
• Python 3.12
• Biopython (чтение FASTA)
• Matplotlib (график)

Как запустить
1. Установите зависимости: pip install biopython matplotlib
2. Убедитесь, что файл ecoli.fasta лежит в той же папке.
3. Запустите скрипт: python project3.py
